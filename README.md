## Приложение-напоминалка

Приложение написано на Python с использованием tkinter и SQLite3. Напоминания сохраняются в `reminders.db` рядом с файлами приложения. При запуске база и таблица создаются автоматически.

Запуск из PowerShell или командной строки:

```powershell
python main.py
```

Для создания напоминания заполните заголовок, дату в формате `ГГГГ-ММ-ДД`, время в формате `ЧЧ:ММ` и, при необходимости, описание. Приложение проверяет сроки каждую секунду; напоминания, срок которых наступил, получают статус «Просрочено» и показываются в отдельном окне поверх остальных окон. Проверка продолжает работать, пока приложение запущено, в том числе когда главное окно свернуто.

В списке доступны фильтр по статусу, удаление и установка статуса «Готово» или «Отменено».

## Генератор PDF-чеков

Поместите CSV/JSON-файлы в папку `data/` и HTML-шаблоны в `templates/`, затем выполните:

```powershell
pip install -r requirements.txt
python pdfcheck.py
```

На Windows для WeasyPrint может потребоваться установленная GTK3 Runtime. На macOS системные библиотеки Pango можно установить через Homebrew:

```powershell
brew install pango
```
