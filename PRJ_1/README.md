# CLI-хранилище паролей

Требуется Python 3.10+ и пакет `cryptography`.

Установка и запуск в PowerShell из папки `PRJ_1`:

```powershell
python -m pip install -r requirements.txt
python ".\Генератор паролей" --help
```

При первом запуске команда попросит создать мастер-пароль и подтвердить его.
В последующих запусках потребуется ввести мастер-пароль. Команды:

```powershell
python ".\Генератор паролей" add
python ".\Генератор паролей" get Google
python ".\Генератор паролей" list
python ".\Генератор паролей" delete Google
python ".\Генератор паролей" new
python ".\Генератор паролей" new --length 32
```

Если для `get` или `delete` не указать название, программа запросит его
интерактивно. Пароль новой записи вводится без отображения на экране.

Файл `passwords.db` хранит записи и SHA-256 хеш мастер-пароля с солью.
Пароли записей зашифрованы Fernet; ключ хранится в локальном файле `.key`.
Сделайте резервные копии обоих файлов: без `.key` сохранённые пароли
расшифровать нельзя. Не публикуйте и не передавайте файл ключа.
